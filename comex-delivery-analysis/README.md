# comex-delivery-analysis

从 CME/COMEX 金属期货交割报告中提取指定品种、月份和机构的数据，汇总交割数量、参与者排名、集中度及跨月变化。

分类：市场与宏观。版本见 [skill.json](skill.json)，变更记录见 [CHANGELOG.md](CHANGELOG.md)。

## 什么时候用

- 用户提供白银、黄金、铜、铂、钯或铝等品种的交割报告 PDF 或表格。
- 需要找出某个月的主要交割参与者、计算集中度或核对汇总数字。
- 需要对比多个有明确报告日期的月份，观察参与者结构变化。

## 输入要求

提供报告文件或可访问的原始链接，并说明品种、分析月份和报告日期。截图应包含完整表头、单位、目标月份和总计行。跨月比较需要对应月份的数据，缺失值保留为未知。

原技能对列名有特定解释。复用前应根据实际报告的官方表头及图例核对字段含义，不应将某种模板的列名套用到所有交割报告。

## 输出内容

- 报告来源、品种、日期、月份与单位。
- 按源报告字段提取的机构明细、分项汇总与总计核对。
- 主要参与者排名、占比、Top 3/5 与 HHI 等集中度指标。
- 有足够数据时给出月度变化和需要进一步核验的结构性观察。
- 标注缺失项、提取不确定性及解释限制。

原始流程见 [SKILL.md](SKILL.md)。本次仅完成迁移和包结构整理，没有对其中所有市场解释作重新验证；原文中的比例阈值和解释应作为待检验假设，不作为已证实的预测结论。

## 示例请求

- “使用 comex-delivery-analysis，提取这份白银交割报告的本月机构明细，核对合计并列出前五名。”
- “比较这两个月的黄金交割报告，说明集中度和参与者变化，区分数据与推断。”
- “先核对报告表头含义，再计算各机构占比；缺失数据不要补零。”

## 环境与依赖

需要 Agent 的 PDF/表格读取能力；计算汇总和集中度时可使用 Python。没有强制的同仓库技能依赖，也不需要券商账户凭据。

## 安装与复用

在仓库根目录运行：

```bash
python3 scripts/install.py comex-delivery-analysis
python3 scripts/install.py comex-delivery-analysis --apply
```

第一条命令预览，第二条安装到默认共用技能目录。手动复用时复制整个文件夹。此次仓库整理没有自动将它安装到任何 Agent。
