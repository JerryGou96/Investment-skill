# 美股跨资产周报

为 Jerry 生成每周美股跨资产复盘。必须把股票、利率、美元、大宗商品、加密货币、
波动率和信用市场连接起来，解释市场主线、板块轮动及未被确认的风险信号，并据此形成
有条件、有触发位、有失效条件的下周交易剧本。

本技能负责研究、分析、质量检查和报告格式。定时任务及发送路由由外部系统负责。
默认定时运行时间为每周五 13:10，时区为 `America/Los_Angeles`。

单日收盘复盘使用 `us-market-close-recap`。只有用户提供账户或持仓数据时，才使用
`daily-portfolio-review`。不得根据 Jerry 的长期关注主题推测其实际持仓。

## 中文输出硬性规定

- 所有面向用户的叙述、标题、表头、结论、风险提示和交易剧本必须使用中文。
- 股票代码、资产代码、机构专名及 `BMO`、`AMC`、`TBD` 可以保留英文。
- `Risk-On`、`Risk-Off`、`Regime`、`Trigger`、`Invalidation` 等术语如需保留，
  必须先给出中文含义或使用“中文（英文）”形式。
- 不得出现整段英文说明、全英文标题或全英文表头。
- 引用英文来源时，来源标题可以保留原文，但对其结论的概括必须使用中文。

## 默认参数

| 参数 | 默认值 | 执行规则 |
|---|---|---|
| 输出语言 | 简体中文 | 必要市场术语和 ticker 可保留英文 |
| 读者 | Jerry / 主动交易者 | 直接、证据导向、强调交易含义 |
| 数据截止时间 | 执行时刻 | 标明时区及美股现金市场是否已经收盘 |
| 统计周 | 最近一个完整美股交易周 | 不得把未结束的周五当成完整周 |
| 报告时区 | `America/Los_Angeles` | 美国事件同时显示 ET 和 PT |
| ETF 收益口径 | 有可靠复权数据时使用总回报 | 市场点位另列原始收盘价 |
| BTC 取样口径 | 对齐周五美股现金市场收盘 | 无法对齐时披露日线时区 |
| 输出形式 | 3–6 条聊天摘要 + 完整 Markdown 周报 | 无法附加文件时直接在聊天中输出全文 |
| 市场状态置信度 | 中等 | 只有证据充分时才上调 |
| 缺失的可选栏目 | 省略或写“本周无重要事项” | 不得为了完整而填充无效内容 |
| 个性化 | 优先使用获准访问的长期关注主题 | 不可用时使用第 6 步的默认关注清单 |
| 交易想法 | 条件式研究情景 | 不得强行给出多头或空头机会 |

## 第 1 步：检测可用工具和数据路径

检查当前环境中可用的金融数据工具、技能、网页搜索能力、运行时和已认证数据源。
数据方法必须在实际使用它的运行环境中测试，不得假设另一个运行时已经安装相同依赖。

**价格数据决策树：**

1. 如果存在专用市场数据工具或金融数据技能，优先使用。
2. 否则，如果当前运行时可以使用 Python 和 `yfinance`，使用该路径。
3. 否则，使用可信行情网页或交易所公开页面。
4. 如果没有任何实时路径可用，仍生成部分周报，将相关字段标为“数据不可用”，
   并说明限制。不得使用模型记忆中的价格补齐。

**新闻和日历决策树：**

1. 宏观发布时间、Fed 信息、公司事件和政策会议优先使用官方来源。
2. Reuters、AP 或同级别财经媒体用于交叉验证和本周叙事梳理。
3. 聚合网站只能用于发现线索或备用，重要日期必须另行确认。
4. 无法确认准确时间时写 `TBD`，不得估算。

**个性化决策树：**

1. 如果 AgentBrain 或其他获准的记忆来源可用，只读取与本周市场相关的长期主题。
2. 不可用时使用第 6 步的默认 Jerry 关注清单。
3. 个性化数据缺失不得阻断周报生成。

**本步交付物：**记录采用的数据路径、备用路径及不可用能力。

## 第 2 步：锁定数据截止时间和统计区间

首先判断本周最后一个美股现金交易时段是否已经结束。

- 本周最后一个交易日收盘后：使用本周最后一个有效交易日与上周最后一个有效交易日。
- 本周尚未收盘：默认使用最近一个已经完整结束的交易周，并明确说明本周仍未结束。
- 节假日缩短交易周：使用实际最后交易日，并在报告中明确标注。
- 延迟行情：必须标注行情时间戳和“延迟”状态。

统一使用以下计算规则：

- ETF/股票周回报：复权数据可靠时使用 `期末复权价 ÷ 期初复权价 - 1`。
- ETF/股票展示点位：使用原始收盘价，并与总回报明确区分。
- 美债收益率变化：`（期末收益率 - 期初收益率）× 100`，单位为 bp。
- VIX：同时报告期末水平、点数变化和百分比变化。
- 美元、黄金、原油和 BTC：报告百分比变化，并注明代理资产或取样口径。
- 不得在没有说明的情况下混用不同日期或不同时区的周度端点。

**进入下一步的条件：**两个统计端点及其交易状态均已确认。

## 第 3 步：收集并核验数据

最低数据集如下：

| 模块 | 必需数据 |
|---|---|
| 跨资产 | GLD、BTC-USD、5Y 收益率、30Y 收益率、DXY、原油、VIX、TLT |
| 美股指数 | SPY、QQQ、DIA、IWM |
| 11 个行业板块 | XLE、XLV、XLP、XLK、XLF、XLC、XLI、XLU、XLB、XLRE、XLY |
| 确认指标 | 条件允许时加入 RSP/SPY 宽度代理及 HYG/LQD 信用代理 |
| 重点主题 | SMH 或 SOXX、IGV，以及本周重要领涨股和领跌股 |
| 下周催化剂 | 官方宏观、Fed、Treasury、全球央行和公司 IR 日历 |

核验规则：

- 复核日期、单位、拆股、分红、复权方式及明显异常值。
- 独立复算最强和最弱指数、板块的周度表现。
- 重大宏观或公司结论使用一个一手来源，或两个可信二手来源确认。
- Fed 降息定价等快速变化数据必须记录抓取时间。
- 来源冲突时优先采用一手来源；差异重大时在报告中说明。
- 没有直接证据时，不得把相关性写成因果关系。

**降级条件：**必需跨资产项目中超过两个无法取得时，将市场状态置信度降为“低”，
并把结论标为“暂定判断”。

## 第 4 步：排名市场领导力和板块轮动

使用相同统计端点和收益口径，对 11 个行业 ETF 从强到弱排序，并比较：

- QQQ、SPY、IWM 之间的相对表现，以及 RSP 相对 SPY 的宽度；
- SMH/SOXX 相对 IGV；
- 周期板块相对防御板块；
- TLT、利率敏感板块与长端美债收益率；
- BTC、高 beta 股票与美元、流动性代理；
- 条件允许时比较 HYG 与 LQD。

明确说明资金买入了什么、卖出或回避了什么，并把轮动归类为：
“全面扩散”“窄幅领涨”“杠铃结构”“防御轮动”“久期驱动”“利率冲击”或“拥挤交易反转”。

**本步交付物：**前三强板块、后三弱板块、市场宽度及本周主要轮动类型。

## 第 5 步：判断宏观市场状态

使用五个核心支柱：股票宽度、波动率、利率/久期、信用市场、美元/流动性。
一个市场状态至少需要三个相互独立的支柱确认。

| 市场状态 | 典型确认信号 |
|---|---|
| 全面风险偏好（Clean Risk-On） | 股市普涨、VIX 回落、信用稳定，且没有破坏性的利率或美元冲击 |
| AI 主导风险偏好（AI-Led Risk-On） | QQQ/SMH 领涨、宽度偏窄，但波动率受控 |
| 杠铃型风险偏好（Barbell Risk-On） | 成长/周期与防御/久期资产同时走强，跨资产信号混合 |
| 高位震荡（High-Level Chop） | 指数变化不大、内部轮动剧烈、方向确认不足 |
| 防御轮动（Defensive Rotation） | 防御和久期资产领涨，宽度、信用或波动率恶化 |
| 流动性压力（Liquidity Stress） | 股票、信用、BTC 走弱，VIX 通常与美元同时走强 |
| 增长担忧（Growth Scare） | 收益率、原油和周期股下跌，久期及防御资产走强 |
| 利率冲击（Rate Shock） | 长端收益率快速上行，久期、地产、公用事业或长久期成长股承压 |

置信度规则：

- **高：**至少四个支柱确认，且没有重大矛盾。
- **中：**三个支柱确认，重大矛盾不超过两个。
- **低：**确认支柱不足三个、关键数据缺失或信号冲突严重。

必须同时报告支持证据、矛盾证据和置信度。没有合适标签时使用
“混合/过渡期（Mixed / Transition）”，不得强行套用叙事。

**本步交付物：**一个市场状态标签、置信度、支持支柱及矛盾信号。

## 第 6 步：形成市场主线和 Jerry 重点

用一个紧凑段落回答：

1. 本周市场主要在交易什么；
2. 哪个资产或因子传导了这轮变化；
3. 谁领涨、谁落后；
4. 哪些信号没有确认主流叙事。

从已经核验的变化中选择 4–7 个 Jerry 重点。默认关注范围：

- AI 半导体和硬件；
- 光通信、网络和 AI 服务器产业链；
- 存储、软件及 SaaS 宽度；
- 加密货币 beta；
- 宏观相关时的材料和能源；
- 医疗及其他防御方向。

不得每周机械列出全部长期主题。只有当主题出现显著价格变化、确认催化剂，
或影响下周交易设置时才能纳入。

**本步交付物：**一个核心市场故事、4–6 个顶部信号和 4–7 个 Jerry 重点。

## 第 7 步：核验下周催化剂

尽可能从一手来源建立下周日历：

- 美国数据：BLS、BEA、Census、Federal Reserve、Treasury 及官方发布日历；
- Fed：官方活动页面及当年 FOMC 投票权；
- 全球政策：相关央行官方网站；
- 财报：公司 IR 优先，其次为交易所或可信财报日历；
- 行业活动：公司或会议官方网站。

准确转换时区。保留 `BMO`、`AMC` 或 `TBD`，不得杜撰具体时刻。
每个重要事件必须说明其影响市场的传导渠道，不能只罗列名称。

**进入下一步的条件：**每个精确的未来日期和时间均有可核验来源；否则标记为 `TBD`。

## 第 8 步：生成交易剧本、完成质量检查并输出

交易想法只有同时满足以下条件，才能进入“多头/加仓”或“空头/减仓/回避”：

- 已核验的证据；
- 可观察的触发条件；
- 明确的失效条件；
- 合理的交易周期；
- 已知催化剂或市场传导机制。

否则只能放入“观察清单”。表格允许写“本周没有符合条件的交易设置”。
除非用户提供持仓和风险约束，否则不得给出仓位比例。

输出前必须检查：

- 所有章节采用同一统计区间；
- 收益率、bp 变化和单位复算无误；
- 强弱排名与底层数据一致；
- 每个精确催化剂时间均有来源并正确转换时区；
- 所有事实截至所标注时间仍然有效；
- 每个交易想法都有触发条件、周期和失效条件；
- 聊天摘要与完整报告结论一致；
- 缺失、延迟、估算及冲突数据均已显著标注；
- 面向用户的内容符合“中文输出硬性规定”。

### 必需输出结构

先发送 3–6 条适合 Discord 阅读的中文摘要：

1. 市场状态及置信度；
2. 主要领导方向和板块轮动；
3. 最重要的跨资产确认或背离；
4. 最大风险；
5. 下周最重要的观察点；
6. 一句话结论。

随后提供或附加 Markdown 完整报告，标题为：

`美股跨资产周报｜YYYY-MM-DD`

完整报告必须包含：

0. **数据区间与跨资产快照**  
   标明数据截止时间、统计端点、收益口径、数据路径和限制。表头为：  
   `资产 | 代理代码 | 期初 | 期末 | 周度变化 | 交易解读`

1. **宏观市场状态与顶部信号**  
   包含“市场状态”“置信度”“支持证据”“矛盾证据”“核心市场故事”及 4–6 个信号。  
   每个信号包含：`为什么重要 | 当前设置 | 交易含义 | 触发条件 / 失效条件 / 周期`

2. **本周市场复盘**  
   包含主要指数表现、11 板块排名、前三强/后三弱、轮动类型、重点主题及 Jerry 关注项。

3. **下周催化剂**  
   包含：
   - “美国经济事件”：`日期 | 时间 ET / PT | 事件 | 重要性 | 市场影响 | 来源`
   - “Fed 官员讲话”：`日期 | 时间 ET / PT | 官员 | 当年是否有投票权 | 潜在影响 | 来源`
   - 必要的全球政策观察；
   - “重点财报”：`日期 | 代码 | 公司 | BMO/AMC/TBD | 关注点 | 板块影响 | 来源`

4. **下周交易剧本**  
   使用“多头/加仓”“空头/减仓/回避”“观察清单”三张表：  
   `代码/资产 | 证据 | 设置 | 触发条件 | 周期 | 失效条件 | 置信度`  
   最后写“一句话结论”以及 2–4 条需要监控的风险线。

5. **来源与数据限制**  
   列出可点击的一手或可信来源、数据时间戳、使用的备用来源及未解决限制。最后注明：  
   `本报告仅用于市场研究，不构成针对个人情况的投资建议。`

无法附加文件时，直接在聊天中输出完整周报。不得只返回本地文件路径。
